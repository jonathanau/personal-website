A modern, Lua-based Neovim setup with a lineage tracing back to my vimrc from 2005. Built around lazy.nvim for plugin management, Mason for automatic LSP installation, Telescope for fuzzy finding, and Treesitter for syntax highlighting. Includes a Ghostty integration that wraps Neovim as a native macOS app, launchable directly from Spotlight.
